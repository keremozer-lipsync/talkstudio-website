# TalkStudio / AniStudioLS Beta Website

Static landing page for TalkStudio and AniStudioLS.

## Edit text
Open `index.html` and change the visible text directly.

## Replace screenshots
The three visual cards in the "Uygulamadan" section are currently CSS mockups.
They can later be replaced with real screenshots.

## Download button
In `index.html`, find:
`<a class="button primary big" href="#">Beta'yı İndir</a>`

Replace `#` with the URL of your GitHub Release/download page.

## Publish
This project is ready for GitHub Pages, Cloudflare Pages, or another static hosting service.
